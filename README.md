# Abhinav Kumar Singh — GertiX Studio Redesigned Portfolio

A brutalist, technical, high-performance developer portfolio for **Abhinav Kumar Singh** (Full Stack Developer Intern @ Easy Insights Pvt. Ltd.), designed and architected as per the design language of **[GertiX Studio](https://gertix.studio/)**.

---

## 🎨 Design System & Aesthetic (GertiX Studio DNA)

1. **Typography & Styling**:
   - Primary Font: **IBM Plex Mono** (technical uppercase numerals, navigation tags, badges, code labels).
   - Display Font: **Space Grotesk** & **Syne** (geometric brutalist typography).
   - Color Palette:
     - Neutral Canvas: `#f2f2f2` (`var(--neutral-100)`)
     - Light Gray Surface: `#e8ebeb` (`var(--neutral-200)`)
     - Technical Dashed Borders: `#9bacae` (`var(--neutral-300)`)
     - Charcoal Black: `#17181a` (`var(--neutral-600)`)
     - Signature Chromata Teal: `#25b895` (`var(--chromata-400)`), `#136157` (`var(--chromata-600)`)

2. **Signature GertiX Components**:
   - **Dual-Block Sliding Arrow Button (`.cb-button`)**: Title and arrow compartment with infinite horizontal slide animation on hover.
   - **Fixed Monospace Header (`.cb-site-header`)**: Numbered sections (`01 Home`, `02 Overview`, `03 Experience`, `04 Disciplines`, `05 Projects`, `06 Skills`, `07 Education`, `08 Contact`) with transparent-to-solid scroll transitions and mobile burger menu.
   - **Hero Frontpage (`.cb-block--hero-frontpage`)**: Full viewport height with interactive technical blueprint canvas, text glow typography, and an infinite marquee ticker track.
   - **Statement & Metrics Grid (`.cb-block--statement-text`)**: Central crosshair divider, interactive pill tokens that invert on hover, and 4-card KPI metric grid (`2026 Graduating`, `100+ Records`, `95% AI Relevance`, `2.8k+ Tasks Queued`).
   - **Production Experience Spotlight (`.cb-block--text-animation`)**: Sticky editorial heading with gradient fill and interactive workstation terminal (`abhinav@workstation:~$`) with live tabs.
   - **Five Core Disciplines (`.cb-block--business-areas`)**: Numbered deep-dive cards with technical metadata frames and custom illustration previews.
   - **Featured Projects Gallery (`.cb-block--post-gallery`)**: Horizontal sliding track with dashed borders, clip-path image frames, and expanding hover drawers with sliding underline links.
   - **Tech Ecosystem Grid (`.cb-block--logo-gallery`)**: Accreditations, tools, and company recognition badges with hover scaling.
   - **Education & Timeline Grid**: Clean academic journey cards for B.Tech IT, Diploma, and Schooling.
   - **Interactive Resume Modal**: Real ATS structured resume preview, raw `.tex` LaTeX source code viewer with one-click clipboard copy, and direct PDF download.
   - **Contact Section & Footer**: Minimalist dashed input underlines, direct WhatsApp/Email/LinkedIn/GitHub copy triggers, and dark footer with mouse-following radial spotlight.
